# WEATHER_DASHBOARD

Weather Dashboard Application using Python

## Installation

Clone this repository:

git clone https://github.com/your-username/weather-dashboard.git

Install dependencies:

pip install -r requirements.txt

Run the application:

python -m src.main --help

## Usage

usage: main.py [-h] [--city CITY]

optional arguments:
  -h, --help            show this help message and exit
  --city CITY           City name for weather forecast (required)

Provide a city as an argument to get the weather forecast.

### Example:

python -m src.main --city London
